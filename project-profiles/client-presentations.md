# Public Building presentation assets

The public React template renders enabled modules only. Empty media and authoring/release diagnostics do not render. Exterior-only projects get Overview, Front, Corner, Entry view and Aerial camera presets; reviewed floor controls remain available on configured projects. Published scene settings may provide `presentation.description`, `presentation.location` (finite latitude/longitude/address), `presentation.gallery` (published media keys/captions), and `presentation.contact` (phone/email/label).

Optional recovery packs live in `apps/public/public/presentations/<immutable release manifest SHA-256>/manifest.json`. They contain source-derived material definitions, optimized WebP bitmaps and publication-approved reference imagery. The runtime checks the release manifest digest and model ID before accepting the pack, then hashes the downloaded model bytes before applying recovered material colors/textures. A different model/release fails closed to its original materials. Scene geometry, model identity, version and immutable model bytes stay unchanged. The pack is data, separate from the generic renderer and JS bundle.

The initial recovery pack was extracted from the supplied SketchUp backup (source SHA-256 recorded in the pack). Its material XML names match FBX/GLB material names after normalization; unmatched definitions are excluded. Textures are resized to at most 512px, retain source UVs and use WebP quality 88. The exterior reference is supplied project artwork, labelled as a reference, not as a screenshot of the live model. No colors are inferred from that artwork.

A new immutable release requires a matching recovery pack (or preferably a GLB exported with the recovered source materials using the existing Studio SketchUp texture recovery pipeline). Do not copy the old release digest into a new pack without verifying the new model bytes and source definitions. Recovery packs are additive presentation data; they do not modify R2/D1 release records.

Generic landscaping is decorative: road, curb, planting, lamps, simple parked cars and distant context massing. It is opt-in for the client exterior viewer, omitted when reviewed site elements or included source site geometry exist, and marked `presentationOnly`/`nonAuthoritative` at runtime. Source-backed site elements retain their instanced renderer. No decorative environment claims survey accuracy. Exact map embeds require configured coordinates; a locality-only record uses a clearly labelled locality search. Contact and floor/interior features require published data.

Cloud drift and reveal motion respect reduced-motion preferences. Camera movement stops on user interaction. Rendering pauses while the tab is hidden. Camera fitting accounts for both portrait and landscape viewports; source camera presets remain unchanged outside the opt-in client presentation.
